Convert Mycaches

Convert Mycaches is a Chrome packaged app that converts HTML from the geocaching.com Your Profile page into a HTML-formatted list of geocaches suitable for posting to Livejournal or Dreamwidth.

This app is implemented as a single HTML file with embedded Javascript to do the conversion. The other files are for Google Chrome to manage it as an extension.

Since this app is not in the Chrome Web Store, you have to install it by selecting "Load unpacked extension..." in the Chrome Extensions page with Developer mode enabled.
